# Zabbix Deploy

This repository is reserved for the Zabbix monitoring deployment automation.

## Migration status

The source migration from `VuTruc/zabbix-monitoring-deploy` has not completed. The automation files are not yet available on this branch, so this repository is **not ready to install from**.

The source contains deployment scripts for Oracle Linux, Zabbix, MariaDB, Apache/PHP, Syslog, Oxidized, Telegram and TACACS+. Before publishing the complete tree to this public repository, the remaining script files need to pass the repository publishing checks.
